# مشروع ماركت وعطارة ابن سينا

## محتويات المشروع
- `www/index.html`: المتجر العربي المتجاوب.
- `package.json` و`capacitor.config.json`: إعداد تغليف الموقع كتطبيق أندرويد.
- `.github/workflows/android.yml`: بناء APK تلقائيًا عبر GitHub Actions.

## المميزات
- المنتجات الافتراضية والأسعار بالجرام.
- سلة مشتريات والتحقق من المخزون.
- حفظ الطلبات والمنتجات في تخزين المتصفح المحلي.
- تجهيز رسالة الطلب وفتح واتساب.
- لوحة إدارة لإضافة/تعديل/حذف المنتجات، تحديث المخزون، متابعة الطلبات وحالاتها.
- تصدير نسخة احتياطية JSON.

## بناء APK من هاتف أندرويد فقط عبر GitHub
1. نزّل ملف ZIP وارفع محتوياته إلى مستودع GitHub جديد. ارفع **محتويات** المجلد وليس المجلد الأب نفسه.
2. من صفحة المستودع افتح **Actions** وفعّل GitHub Actions إذا طُلب منك.
3. افتح سير العمل **Build Ibn Sina Android APK** ثم اضغط **Run workflow**. ويمكن أيضًا تشغيله تلقائيًا بعد push إلى الفرع `main`.
4. انتظر حتى يصبح التشغيل أخضر، وافتح التشغيل المكتمل.
5. في قسم **Artifacts** اضغط `ibn-sina-debug-apk` لتنزيل ملف ZIP الذي بداخله `app-debug.apk`.
6. فك الضغط على الهاتف، افتح `app-debug.apk` وثبّته. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.

## أول تشغيل وإعداد
- رمز لوحة الإدارة الافتراضي: `1234`. افتح الإدارة وغيّره فورًا.
- رقم واتساب المبدئي مُدخل بصيغة مصر الدولية `201093337992`. راجعه من لوحة الإدارة.
- فودافون كاش وإنستا باي معروضان كبيانات إرشادية؛ التطبيق لا يتحقق من الدفع تلقائيًا.
- اضبط الأسعار والمخزون الفعليين من لوحة الإدارة قبل البيع.

## حدود مهمة في هذه النسخة
هذه نسخة أولية تعمل دون خادم. البيانات محفوظة على نفس تثبيت التطبيق/المتصفح، ولا تتزامن تلقائيًا بين هاتف العميل وهاتف المحل أو بين عدة أجهزة. مسح بيانات التطبيق أو إلغاء تثبيته قد يحذف البيانات؛ استخدم تصدير النسخة الاحتياطية بانتظام. إرسال واتساب يتطلب إكمال الضغط على إرسال داخل واتساب. رمز الإدارة محلي وليس نظام أمان احترافيًا. لبيع فعلي متعدد العملاء مع قاعدة بيانات مركزية، يلزم ربط المشروع بخادم وقاعدة بيانات وتسجيل دخول آمن.
